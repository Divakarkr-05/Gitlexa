# Module Guide: Infrastructure & Cloud Security

This guide outlines the scope, responsibilities, and security boundaries for cloud resources, deployment, and infrastructure.

> **Note**: [.ai/TEAM_ROLES.md](file:///c:/Users/Divakar%20K%20R/Gitlexa/.ai/TEAM_ROLES.md) remains the authoritative source for overall team responsibilities.

## Module Responsibilities
- **Current Contributors**: Member 01 (Cloud Security Architect)
- **Scope**: AWS Bedrock access policies, IAM least-privilege configurations, Secrets Manager, CloudWatch monitoring, Docker & Terraform setups.
- **Security Boundaries**:
  - Strict zero-secrets-in-plaintext policy across all environments.
  - All cloud resource configurations must be declarative and reproducible.

# Member 04: Frontend Development

## Ownership
- **Directories**:
  - `frontend/`
- **Technologies**: React 18, Vite, TypeScript, Lucide Icons, Vanilla CSS / modern UI aesthetics.

## Core Responsibilities
1. **Web Dashboard**:
   - Build responsive, dark-mode first telemetry and blocker exploration dashboards.
   - Implement interactive evidence cards, blocker severity badges, and CI status visualizers.
2. **API Consumption**:
   - Integrate with backend `/api/v1` endpoints (Health, Projects, Analysis, Auth).
   - Ensure clean separation between data hooks, UI components, and TypeScript domain types.

## Strict Boundaries
- Zero direct connections to GitHub or AWS from the frontend. All data must flow through backend APIs.
- Do not implement backend or voice logic.
